# 趋势结构浪形判断方法（三浪结构）

> **最终目标**：利用**三浪结构**（上涨为 **1-2-3 浪**、下跌为 **A-B-C 浪**）及辅助指标，对个股给出**趋势结构得分**，判断是否**扭转下跌趋势并进入上涨趋势**，以及是否处于两类**合适买点**之一。模型应输出：得分、强弱结论、趋势与买点判断。

---

## 一、目标与输出

### 1.1 本方法要回答的问题

建议按下列顺序作答（先位置与定性，再定量打分）：

1. **近期是否出现下跌三段**？（下跌三段 A-B-C **已能合理划分**，含完整或接近完整，使用上、下影线表示的最高、最低价判断）。

2. **是否扭转波峰，改变下跌趋势**？（**拐点右侧最高价 ≥ 下跌 A-B-C 段内任一波峰（从右往左看）**；常结合：回踩是否**不创新低**等）。

3. **近期一段**（当前可见的主要波段）走势相对**强**还是**弱**？（可结合 §2.3、量能、MACD、K 线力度等简述。）

4. **趋势结构得分**是多少（建议 0～100）？并给出与得分区间对应的**强弱结论**（强 / 中强 / 中性 / 偏弱 / 弱，见 §4.2）。

5. 当前是否处于**合适买点**？两类：**①2 转 3 买点**——上涨趋势已形成后，**2 浪转 3 浪**的拐点；**②拐点买点**——**下跌三浪（A-B-C）结构走完整**，且出现**强势上攻**信号时的可参与位置。

*说明*：若**近期无可适用的下跌三段**（例如大级别已处于清晰上涨），第 1 问可答 **否 / 不适用**并简述当前 **1-2-3 浪**位置；**仍按第 2～5 问顺序作答**（第 2 问可从「此前是否已扭转波峰」「当前是否在上涨回踩中」等你方情形作答）。

### 1.2 模型建议输出格式

**顺序与 §1.1 完全一致。**

| 顺序 | 输出项 | 说明 |
|:----:|:-------|:-----|
| 1 | **下跌三段（A-B-C）** | 近期是否**可合理划分**下跌三段（完整或接近完整）；若**不适用**，注明并写出当前 **1-2-3** 或震荡及大致区间 |
| 2 | **扭转波峰** | 是否已**扭转下跌趋势**（**最高价 ≥ 下跌 A-B-C 段内任一波峰**，§2.2）；回踩是否**不创新低**（C 浪低点）等 |
| 3 | **近期波段强弱** | 相对强 / 弱 / 中性及理由（§2.3、量能、MACD、K 线） |
| 4 | **趋势结构得分与强弱结论** | 得分 **0～100**（§4.1 四维汇总）；结论 **强 / 中强 / 中性 / 偏弱 / 弱**（§4.2，按情形选用「2 转 3」或「拐点买点」表） |
| 5 | **合适买点** | 是否处于 **2 转 3** 或 **拐点**（§4.3，建议得分 ≥60）；否则说明原因 |
| — | **主要依据**（附） | **扭转强弱、回撤比例、时间、MACD（3.4.1+3.4.2）** 等简要一句；量能见 §2.3 |

**符号约定**：下跌三段与上涨三段**统称三浪结构**。其中涨用 1-2-3（如上涨 1 浪）、跌用 A-B-C（如下跌 C 段），避免混用。

**拐点**（须区分情形）：在**下跌 A-B-C** 中，本方法所称与「跌转涨 / 对比波峰」配套的 **拐点**专指 **C 浪终点**（C 段下跌结束时的价位或末端区域），即本轮下跌三浪在结构上的**末端**；**不是**泛指任意反弹高、低。用于判定是否扭转下跌趋势时，**对比波峰**须与 **A-B-C 划分**及图上 Peak 标记对齐；**首要参照** **下跌 A 段起点** 右侧、**下跌 C 段终点** 左侧的 **阶段波峰**（下跌始发、进入 A 浪前的反弹高点）。扭转判据见 **§2.2 第 2 点**（**最高价 ≥ 该段内任一波峰**）。**上涨 1-2-3** 中的「拐点」仍指 **2→3** 等推动转换处，勿与 C 段终点混读。

### 1.3 走势与浪段特征的表述优先级（波峰扭转）

在输出**走势位置**、浪段表格中的「特征描述」或文字结论时：

1. **若已判定跌转涨、并扭转下跌结构中的对比波峰（前高）**（判定见 **§2.2 第 2 点**、§4.4：**最高价 ≥ 该下跌 A-B-C 段内任一波峰**；对照时**优先 A 浪起点侧阶段峰**，勿取 B 顶）：描述当前 **1 浪**或**首轮上攻**时，**必须优先写清结构含义**——写明 **所对照的对比波峰（或峰组）**、**何日（或何线）最高价首次达到或突破该波峰**、与 **A-B-C** 的**位置关系**；可配合放量阳线、回踩不破前低等。**均线、MACD** 仅作**辅助印证**，**不得**作为**唯一或首要**特征句。
2. **若已扭转波峰**、但价格处于 **1 浪拉升后段**或短线乖离偏大：**交易建议上宜提示**等待 **2 浪缓跌回踩**（缩量、回踩不破扭转后的关键支撑或「前高转支撑」）再评估参与，与 §4.3「中段可跟踪、非最佳买点」及 **2 转 3** 思路一致；**不宜**仅因短期突破均线即表述为「可重仓买点」。

## 二、三浪结构（基础）：涨用 1-2-3、跌用 A-B-C

与 §1.2 约定一致：**上涨趋势**书面与读图优先用 **1、2、3 浪**；**下跌趋势**优先用 **A、B、C 浪**（同属**三浪结构**，仅标签不同）。

### 2.1 定义

**上涨三浪（1 → 2 → 3）**

| 浪 | 方向 | 含义 |
|:---|:-----|:-----|
| 1 浪 | 涨 | 第一段上攻，连续、方向单一、斜率相对清晰，终于一段时间内的局部最高点（上影线） |
| 2 浪 | 跌 | 对 1 浪的修正；**2 浪底不低于 1 浪起点** |
| 3 浪 | 涨 | 与 1 同向；常走强、创新高；若迟迟未能创新高或力度弱，需警惕是否仍处 **2 浪延伸** 或级别误判（布局 **2 转 3** 宜结合 §4.3，在 3 浪启动信号清晰时参与） |

**下跌三浪（A → B → C）**

| 浪 | 方向 | 含义 |
|:---|:-----|:-----|
| A 浪 | 跌 | 第一段下跌，A 浪起点为局部最高价（上影线） |
| B 浪 | 涨 | 反弹修正；**B 浪顶不高于 A 浪起点**（下跌结构不被破坏） |
| C 浪 | 跌 | 与 A 同向，下跌延续或加速，终于局部最低点（下影线）；**C 浪终点**即本方法在下跌情形下的**拐点**（见符号约定），跌破 A 浪低点常表示三浪结构在价格意义上走完整，是否转势需结合底背离与启动 K 线等 |

- **拐点识别**：**下跌 A-B-C** 以 **C 终点**为结构末端锚点；**上涨 1-2-3** 以 **2→3** 等转换为拐点情形。转折处宜有**启动信号**（如放量大阳/大阴）；底/顶附近结合 MACD 背离可提高可信度。

### 2.2 识别要点

**不要求**按「先第一浪、再第二浪、再第三浪」的顺序机械标号。先确定**是否存在完整三段下跌结构**，寻找最近一次完整的三段下跌结构，A 浪高点 （下跌起点）按照对应 K 线的最高价（上影线）、C 浪低点（拐点）按照 K 线最低价（下影线）进行确定，整个下跌过程通常包含两个或以上的 Peak 波峰。随后按照顺序确立当前所处位置：
- 若下跌三段右侧的价格未扭转超过**三段下跌中的任意波峰**，则考虑**拐点买点**，此时**优先**判断 **MACD 底背离程度**——是否 **多次背离**、**背离幅度大**（§3.4.2），并是否出现 **放量大阳线** 作为 **扭转信号**；否则仍可能处于下跌趋势中。

- 若 **下跌三段右侧** 股价最高价 **大于或等于** 下跌 **A-B-C** 三段中的 **任一波峰**（从 C 段终点从右往左开始对比直到 A 段高点），且未走出对应级别（**上涨幅度**、**持续时间**与下跌三段类似）的上涨三段，则考虑**2 浪转 3 浪买点**（或**2 转 3 买点**）。此时需估计扭转——回踩期间的价格走势是否强足够强：
   - 扭转期间强势的判断标准为：**大阳线、放量、连续阳线、均线多头排列**
   - 扭转后回踩的强势判断标准为：**回踩时间足够、回踩幅度浅、阴阳线相间**。具体对照 **§3.2** 估计 **2 浪对 1 浪的回撤比例**。**下跌结构中的 B 相对 A 的幅度不套用 §3.2 档位**，再辅以位置与强弱说明即可。


若无法标出两个清晰拐点，或出现**结构破坏**（如上涨中 **2 浪低点跌破 1 浪起点**；下跌中 **B 浪反弹高点高于 A 浪起点** 等），则三浪不成立或需更大级别重数，趋势结构得分应下调或标注「结构不清晰」。

### 2.3 方向性强弱经验（定性）
- **上涨段 / 上涨浪**：**多放量大阳线为强**——上涨过程中**反复出现放量大阳线**，说明资金主动攻击、攻势更足；若仅缩量小阳慢爬，需更多结构与其它维度印证。
- **下跌段 / 下跌浪**：**缓跌为强**——斜率缓和、以小阴或阴阳交错缓步下移，抛压释放较有序；与之相对，**连续放量长阴、急跌**多代表承接弱、结构更脆弱，判强弱时宜区别对待。

## 三、辅助指标与强弱标准（打分依据）

### 3.1 扭转强弱（仅三段下跌后、扭转下跌波峰的过程）



| 判断条件 | 含义 | 趋势结构维度得分建议 |
|:--------|:------|:------------------|
| **条件1：出现 5%以上大阳线** | 扭转时出现幅度超过 5% 的中大阳线，表明多头启动明显 | 满足则可视为强势信号，得分高（22～25/25） |
| **条件2：80% 以上 K 线为阳线** | 扭转阶段（如连续数日）大多数为阳线，说明反攻持续性好 | 满足则偏强，得分中高（18～22/25）|
| **条件3：连续放量** | 扭转期间成交量持续放大，说明资金积极进场 | 满足则加分，未放量则减分（0～8/25） |
| **条件4：均线形成多头排列** | 5/10/20日均线由短到长向上排列，趋势扭转明确 | 满足则结构更佳，得分靠前 |
| **条件5：已扭转下跌过程中的对比波峰** | **拐点右侧**（C 浪终点之后）**最高价 ≥ 本轮下跌 A-B-C 段内任一波峰**（从 C 浪终点开始逐个向左对比），表示价格在结构上**突破下跌段内前高** | **已满足**：可与条件1～4叠加，本维度宜取 **18～25/25**。**尚未满足**：仅有阳线/放量/均线等仍属「反攻未过关」，本维度整体宜 **不超过约 15/25**，或给 **8～14/25**，直至有效突破波峰后再上调 |

*备注：条件1～4 与条件5 可叠加；**条件5** 解决的是「是否已在**价格**上扭转下跌段内的对比波峰」，与 MACD、大阳线等**相互印证**。实际判定须结合三段下跌后右侧 K 线及成交量；条件1～4 至少有一项较清晰时才有打分意义。若仅部分满足或表现一般，宜给予中等或偏低评分。*


### 3.2 扭转后回踩的回撤比例（仅上涨趋势：2 浪相对 1 浪）

**适用范围（必读）**：本节斐波那契档位表**仅适用于已处于上涨趋势、刻画上涨中 2 浪对 1 浪（扭转后的回踩）的回撤比例**。**下跌过程中的 A-B-C**（例如 B 浪反弹相对 A 浪的幅度）**不套用本表**；若当前大级别判定为下跌、尚无明确 1-2-3 上涨结构，本维度宜在输出中注明「§3.2 不适用」或给**偏弱档/保守分**，勿强行用本表数值解释 B 对 A。

| 回撤幅度（2 浪回踩相对 1 浪涨幅） | 含义 | 趋势结构维度得分建议 |
|:---------|:-----|:---------------------|
| ≤38.2% | 浅幅，强势调整 | 高（如 22～25/25） |
| 38.2%～50% | 偏浅，偏强 | 中高（如 18～21/25） |
| 50%～61.8% | 中幅，中性 | 中（如 12～17/25） |
| 61.8%～78.6% | 深幅，偏弱 | 中低（如 7～11/25） |
| >78.6% 或 2 浪跌破 1 浪起点 | 过深或结构破坏 | 低（0～6/25） |

### 3.3 上涨 2 浪调整时间维度（上涨中 2 浪持续时间 vs 1 浪）

| 条件 | 含义 | 趋势结构维度得分建议 |
|:-----|:-----|:---------------------|
| 2 浪持续时间 ≥ 1 浪持续时间，且 2 浪为横盘或缩量缓跌 | 时间换空间，强势整理 | 高（如 22～25/25） |
| 2 浪时间 ≈ 1 浪时间 | 正常调整 | 中高（如 16～21/25） |
| 2 浪时间明显短于 1 浪时间 | 急促回调，偏弱 | 中低（如 8～15/25） |

### 3.4 MACD 与动能（维度满分 25；由两子项相加）

**MACD 维度**固定为 **25 分**，拆成独立的两项，须**分别打分后相加**（仍记在同一「MACD」大类下）：

| 子项 | 满分 | 内容 |
|:-----|:----:|:-----|
| **3.4.1 柱体与金叉/死叉配合** | **15** | 各浪段柱体、叉、动能是否匹配结构（不含背离细则） |
| **3.4.2 背离** | **10** | 底/顶背离是否成立、程度与是否连续（细则见下） |
| **合计** | **25** | 须等于 3.4.1 + 3.4.2 |

#### 3.4.1 柱体与金叉/死叉配合（0～15 分）

**上涨情形中的 MACD 理想信号（找 2 转 3 买点时适用，此时主要看前两浪的表现）**：

| 阶段 | 理想信号 |
|:-----|:---------|
| **1 浪** | 金叉 + 柱状图明显放大 |
| **2 浪** | 柱缩短或收敛，回踩不破 0 轴（**背离**不在本子项重复计分） |
| **3 浪启动** | 再次金叉 + 柱转正放大 |

**下跌情形中的 MACD 理想信号（找拐点买点时适用）**：

| 阶段 | 理想信号 |
|:-----|:---------|
| **A 浪下跌** | 死叉 + 绿柱明显放大（动能释放，下行加速） |
| **B 浪反弹** | 反弹强势，量能放大，金叉或绿柱缩短/翻红 |
| **C 浪缓跌创新低** | 绿柱出现但对应面积小，量能缩减，同时略微创出新低 |


**本子项得分建议（综合三阶段，合计 ≤15）**：

| 综合判定 | 本子项得分 |
|:---------|:----------|
| 三阶段柱、叉配合理想 | 13～15 |
| 多数符合，略有瑕疵 | 9～12 |
| 仅部分符合或动能一般 | 5～8 |
| 混乱、与结构矛盾 | 0～4 |

#### 3.4.2 背离（0～10 分，独立子项）

与价格对比时，**底背离 / 顶背离**在本子项单独计分，**不与 3.4.1 混算**。

**下跌情形中的底背离（找拐点买点时适用）**

- **①** 股价创阶段新低  
- **②** MACD 绿柱（负柱）不创新低（柱子更短、更贴近零轴）  
- **③** 相邻两段下跌中，绿柱所「围成」的面积变小（下行动能衰竭）

**上涨情形中的顶背离（判断局部见顶信号）**

- **①** 股价创阶段新高  
- **②** 红柱不创新高，或红柱面积较上一段上攻收窄

**本子项得分建议**：

| 情形 | 本子项得分 |
|:-----|:----------|
| 无明显可复核背离，或背离不成立 | 0～2 |
| 单侧背离、程度一般 | 3～5 |
| **背离显著**（价与柱、面积关系明确；**下跌底背离**满足 **①②③** 中至少两项清晰；**上涨顶背离**满足 **①②** 清晰） | 6～8 |
| **连续背离**（多轮新低/新高而柱逐级收敛）或**背离极强** | 9～10 |

*说明*：**背离程度越大**、**连续出现**，在本子项内取更高档；与 §2.3 方向性强弱叙述可相互印证。

## 四、趋势结构得分计算

### 4.1 维度与权重（建议）

| 维度 | 权重 | 满分 | 说明 |
|:-----|-----:|-----:|:-----|
| 扭转强弱 | 25% | 25 | **仅三段下跌后、扭转下跌波峰的过程**（§3.1）；非该情形（例如已处于清晰上涨 1-2-3）可注明不适用或保守给分 |
| 回撤比例 | 25% | 25 | **仅上涨趋势、2 浪相对 1 浪**（§3.2）；非该情形（例如未扭转下跌波峰）可注明不适用或保守给分 |
| 时间维度（2 浪 vs 1 浪） | 25% | 25 | **仅上涨趋势、2 浪相对 1 浪**；横盘久、**2 浪时间 ≥ 1 浪**更强 |
| MACD 与动能 | 25% | 25 | **3.4.1 柱体与叉 0～15** + **3.4.2 背离 0～10**（见 §3.4，须分项填报后相加） |
| **合计** | 100% | **100** | 满分 100 |

### 4.2 强弱结论与得分区间

**2 转 3 买点的得分区间与含义**

| 得分区间 | 强弱结论 | 含义 |
|:---------|:---------|:-----|
| 80～100 | 强 | 上涨前两浪（1-2）清晰，回撤浅、时间够、量能配合好，动能确认 |
| 60～79 | 中强 | 上涨前两浪（1-2）可辨，多数维度偏强，可参与 |
| 40～59 | 中性 | 结构或指标一般，观望为主 |
| 20～39 | 偏弱 | 回撤深或量能/动能差，谨慎 |
| 0～19 | 弱 | 结构不清或指标全面偏弱，不参与 |

**拐点买点的得分区间与含义**

| 得分区间 | 强弱结论 | 含义 |
|:---------|:---------|:-----|
| 80～100 | 强 | **A-B-C** 清晰；**MACD 底背离**显著——**多次背离**且**背离幅度大**（§3.4.2）；近端出现 **放量大阳线** 等扭转信号 |
| 60～79 | 中强 | 下跌三段可辨；**背离程度尚可**（至少一次清晰背离）+ **放量阳线**等扭转信号；或背离一般但结构与其它维尚可；已达 §4.3「拐点买点」**得分 ≥60** 时可参与 |
| 40～59 | 中性 | **背离弱、不连续**或幅度有限；缺乏放量大阳扭转信号；**尚未有效扭转波峰**，观望或降仓 |
| 20～39 | 偏弱 | **C 段**未走完疑云、**几乎无可复核背离**；无放量大阳，上攻乏力，假拐点风险高 |
| 0～19 | 弱 | **A-B-C** 无法划分，或仍处下跌推动、**背离与扭转信号均缺**，不参与拐点博弈 |

### 4.3 合适买点判断（与得分结合）

两类「合适买点」并列，**得分均建议 ≥60** 才推荐；二者情形不同，勿混用。

| 条件 | 买点结论 |
|:-----|:---------|
| 趋势结构得分 ≥60，且**上涨趋势已确立**（或推动结构清晰），当前处于 **2 浪末 → 3 浪初** 的拐点（如 **缓跌回踩**、缩量企稳、不破关键低；MACD 再金叉等为辅，见 §1.3） | **合适买点（2 转 3）** |
| 趋势结构得分 ≥60，且**下跌三浪（A-B-C）结构完整**；**拐点买点优先看 MACD 背离程度**——**多次背离**、**背离幅度大**（§3.4.2）为强信号，并需近端出现 **放量大阳线** 等**扭转信号**；**最高价已 ≥ 下跌 A-B-C 段内对比波峰**（**优先 A 浪起点**侧阶段峰，**非** B 顶）作**跌转涨辅助验证**（§2.2、§4.4）。勿以均线金叉代替背离与扭转叙述，见 §1.3 | **合适买点（拐点）** |
| 趋势结构得分 ≥60，但仅处于某推动浪或调整浪**中段** | 可跟踪，非最佳买点 |
| 趋势结构得分 <60 | 不作为「合适买点」推荐 |


### 4.4 跌转涨的辅助观察（非单独打分项）

- **拐点情形**：**优先**核对 **MACD 底背离**是否**多次、幅度大**（§3.4.2），及是否出现 **放量大阳线** 扭转信号（§2.2）。**是否扭转对比波峰**按 **§2.2 第 2 点**（**最高价 ≥ 下跌 A-B-C 段内任一波峰**，勿误用 B 顶作唯一对照）作**辅助**；并观察之后**回踩是否不创新低**（C 浪低点）。与 4.3「拐点买点」相互印证时，仍须用**三浪结构**定义与四维度得分校验。

## 五、执行清单（模型自检）

分析时**先定性，再按四维汇总为 0～100 分**：

- [ ] **位置与强弱**：能否划分 **A-B-C**（否则写 **1-2-3**/震荡）；是否**扭转下跌波峰**（最高价 ≥ 段内对比波峰）、回踩是否不破低；**近期强弱**（方向经验、量能、MACD）是否已写清。
- [ ] **扭转 / 拐点**：若**未扭转波峰**，是否已看 **MACD 底背离**（多次、幅度）与 **放量大阳线**；若属**三段下跌后的扭转过程**，是否已评 **扭转强弱**（大阳/连阳/放量/均线），否则注明不适用。
- [ ] **回撤、时间、量能**（仅适用上涨 2 对 1 浪时评回撤与时间；量能贯穿浪段）：斐波那契档位、2 浪时长 vs 1 浪、1/2 浪量能是否配合；不适用则注明。
- [ ] **MACD**：柱体与金叉/死叉是否匹配结构（**0～15**）与背离是否成立（**0～10**），合计 **≤25**。
- [ ] **结论**：总分、强弱档位（按情形选对应用表）、是否 **2 转 3 / 拐点**买点且 **≥60**。

## 六、与其它方法的衔接

- **背离**：**C 段末** 若出现底背离或顶背离，可提高拐点与买点可信度；在打分上**单独计入 §3.4.2**，不与 3.4.1 混算。
- **形态**：双底/双顶、头肩等可对应「某级别三浪」；**上涨**读 1-2-3、**下跌**读 A-B-C，**2 浪 / B 浪**常对应左肩。
- **波峰（K 线图上的灰色水平虚线，由 `technical_analysis` 脚本按规则标出）**：须与 **A-B-C** 划分对齐后再用于跌转涨判断。

## 七、常见误判与注意点

| 误判 | 纠正 |
|:-----|:-----|
| 把震荡中的一小段当 1 浪（或 A 浪） | 推动浪需连续、斜率明显的单边走势 |
| 2 浪跌破 1 浪起点仍强行数浪（或 **B 破 A** 仍强行定浪） | 破位后应重新数浪或下调得分、标注结构不稳 |
| 3 浪（或 C 浪）未走完就当新趋势 | 需有效突破前高/前低并站稳再提高得分与买点置信度 |
| 忽略量能 | **1/3（或 A/C）放量、2（或 B）缩量**时三浪结构可信度与得分更高 |
| 忽视方向情形 | 下跌看**缓跌**相对更强、急跌破位更弱；上涨看**放量大阳线**堆叠更强（§2.3） |
| **已扭转下跌波峰**，却用「突破 MA5/MA20、MACD 金叉」概括 1 浪特征 | 应**优先**写清**波峰/前高**与结构（§1.3）；均线与 MACD 为辅 |
| 用无关峰与「是否扭转下跌波峰」对比 | 对比对象须为 **A-B-C 下跌三浪中的波峰** |

## 八、小结

- **最终目标**：以**三浪结构**为主线，结合**扭转强弱、回撤比例、时间、MACD** 等维度相互印证，输出**趋势结构得分（0～100）**，并回答**是否跌转涨**、是否处于**合适买点（2 转 3 / 拐点）**。
- **流程**：与 **§1.1** 同序——**①下跌三段可否划分** → **②近期是否扭转下跌波峰** → **③扭转期间强弱** → **④得分与强弱结论** → **⑤合适买点**；打分时用 §4.1 四维；**已扭转波峰时特征描述见 §1.3**。
- **合适买点**：得分 ≥60 时，**上涨趋势内 2→3 拐点**为 **2 转 3 买点**；**下跌三浪（A-B-C）完整后的强势上攻**为 **拐点买点**；否则仅跟踪或观望。
- **方向强弱**：下跌情形**缓跌相对强**、急跌破位相对弱；上涨情形**放量大阳线堆叠相对强**（§2.3）。

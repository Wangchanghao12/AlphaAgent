# 研报生成防错检查清单

## 一、表格格式错误（高发）

### 错误类型
| 错误 | 示例 | 后果 |
|------|------|------|
| 分隔线过短 | `|-----|` | 飞书无法识别为表格 |
| 列数不匹配 | 表头6列，分隔线5列 | 表格错位 |
| 前有空格缩进 | `  |表格|` | 被识别为代码块 |
| 使用文本对齐 | `|{:<10}|` | 非标准Markdown |

### 正确格式模板
```python
# 产业链结构（5列）
print(f"| 上游 | → | 中游 | → | 下游 |")
print(f"|------|---|---|------|---|------|")  # 注意：6个短横线

# 行业市值排名（6列）
print(f"| 排名 | 公司名称 | 市值(亿) | ROE | 毛利率 | PE-TTM |")
print(f"|------|----------|---------|-----|--------|--------|")

# 核心指标对比（4列）
print(f"| 指标 | 公司A | 公司B | 差距 |")
print(f"|------|-------|-------|------|")
```

## 二、kimi_search未执行（高发）

### 问题原因
- 脚本中的 `search_with_kimi` 在独立运行时返回 `None`
- 需要在子代理任务中明确要求使用 `kimi_search` 工具

### 正确做法
```
子代理任务中必须包含：
1. 运行 research_report.py 生成基础报告
2. 使用 kimi_search 搜索验证：
   - "[公司名] 供应商 原材料"
   - "[公司名] 客户 前五大"  
   - "[公司名] 产业链 上下游"
3. 将搜索结果整理后补充到产业链章节
```

## 六、自查流程（每次生成后必须执行）

### Step 1: 表格格式检查
```bash
# 检查分隔线长度
grep "|-----|" 研报.md  # 应该无结果
grep "|------|" 研报.md  # 应该有结果

# 检查表格缩进
grep "^  |" 研报.md  # 应该无结果
```

### Step 2: 内容完整性检查
- [ ] 技术面有"👁️ 视觉分析"子章节
- [ ] 技术面有"📊 技术指标分析"子章节
- [ ] 产业链章节有搜索验证补充内容
- [ ] 已删除趋势反转/仓位管理/买入清单

### Step 3: 飞书渲染测试
1. 复制报告内容到飞书文档
2. 检查所有表格是否正确渲染
3. 检查是否有代码块错位

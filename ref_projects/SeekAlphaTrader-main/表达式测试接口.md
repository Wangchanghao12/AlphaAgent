# /test_expr 表达式测试接口

> 用于在正式回测前，快速验证自定义 **因子表达式** 是否能够被系统正确解析并计算。

---

## 1. 基本信息

- **接口路径**：`POST http://localhost:8001/test_expr`
- **请求格式**：`application/json`
- **响应格式**：`application/json`
- **鉴权**：无

## 2. 请求参数

| 字段 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| `name` | `string` | 是 | 因子名称，用来标识本次测试表达式，纯标识作用。 |
| `expr` | `string` | 是 | 需要测试的因子表达式，内部变量请使用 `$<列名>` 占位符，如 `$close`、`$volume`。 |

> 说明：API 启动时会自动加载项目根目录下的 `.debug/debug_df.csv` 到内存，作为表达式计算所依赖的数据源。若该文件不存在或加载失败，请先在项目根目录准备好该文件。

## 3. 响应字段

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `success` | `boolean` | 是否执行成功。 |
| `message` | `string` | 成功或错误提示信息。 |
| `name` | `string` | 请求中传入的因子名称。 |
| `parsed_expr` | `string` | `$` 占位符替换成 `df['col']` 之后的可执行 Python 表达式。 |
| `sample` | `string` | 计算结果前 5 行数据的 JSON 字符串。 |
| `error` | `string` | 当 `success=false` 时返回的错误信息。 |

## 4. 调用示例

### 4.1 cURL

```bash
curl -X POST http://localhost:8001/test_expr \
     -H "Content-Type: application/json" \
     -d '{
           "name": "my_factor",
           "expr": "TS_STD($close,5)/TS_STD($close,20)"
         }'
```

### 4.2 示例成功响应

```json
{
  "success": true,
  "message": "表达式解析与计算成功",
  "name": "my_factor",
  "parsed_expr": "df['close'].rolling(...)",
  "sample": "{\"2022-01-03 09:30:00\": 0.123, ...}"
}
```

> `sample` 字段仅展示前 5 行结果，用于快速查看输出格式及数值是否正常。

## 5. 错误码与说明

| HTTP 状态码 | 典型 `detail` 内容 | 可能原因 |
| ----------- | ----------------- | -------- |
| `400` | `表达式解析失败: xxx` | 表达式语法错误，`parse_expression` 无法解析。 |
| `400` | `表达式计算失败: xxx` | 变量替换后执行 `eval` 出错，常见于列名不存在、0 做分母等。 |
